# Documentación Técnica: Integración de Gemini AI

## Clave de API y Autenticación
- Las claves que inician con AQ.Ab8RN... son claves de API válidas y activas de GCP / Gemini.
- Se encuentra configurada por defecto en variables de entorno.

## Modelos Compatibles (Probados 200 OK)
- **gemini-flash-latest** (Principal por defecto)
- gemini-3.5-flash (Fallback 1)
- gemini-3.6-flash (Fallback 2)
- gemini-3.7-flash (Fallback 3)

(Nota: los modelos 1.5 y 2.0 fueron dados de baja por Google y devuelven 404)
